# 7Peaks Reads

News, commentary, and blog articles published at [7Peaks Reads](https://sevenpeaksone.github.io/reads/).

Korean: [README.ko.md](README.ko.md).

The approved website/article design is **lime-v1**. Its shared stylesheet, wordmark, standalone article template, assembly helper, common generator, and tests are versioned in [`tools/reads-theme/`](tools/reads-theme/README.md). Read that guide before creating or changing article HTML; do not recreate the former per-article design.

Keep existing article paths, images, categories, archive, search IDs, favorites, and the current publishing workflow. This repository continues using GitHub Pages; article files are not moved to Cloudflare.
